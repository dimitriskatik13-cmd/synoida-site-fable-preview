# ΣΥΝΟΙΔΑ · Δοκιμαστικό site

Ανεξάρτητο αντίγραφο για οπτική και πρακτική αξιολόγηση προτάσεων, μία σελίδα κάθε φορά.

- [Δοκιμαστική έκδοση](https://dimitriskatik13-cmd.github.io/synoida-site-preview/)
- [Αρχική έκδοση, χωρίς αλλαγές](https://dimitriskatik13-cmd.github.io/synoida-site/)

Σελίδες που έχουν περάσει στο δοκιμαστικό στάδιο: Αρχική και Επικοινωνία. Οι εικόνες, οι γραμματοσειρές και τα βασικά εφέ κύλισης διατηρούνται. Η πρόσθετη κάρτα παιγνιοθεραπείας χρησιμοποιεί εικόνα που υπήρχε ήδη στο site. Οι υπόλοιπες σελίδες διατηρούν το περιεχόμενό τους.

Η Επικοινωνία περιλαμβάνει επιλογή κέντρου, άμεσες τηλεφωνικές κλήσεις, τους υπάρχοντες συνδέσμους χάρτη, πραγματικό σύνδεσμο email και αντιγραφή της διεύθυνσης. Στην πάνω μπάρα του κινητού η επιλογή κέντρου αντικαθιστά το μεμονωμένο τηλέφωνο Σπάτων μόνο σε αυτή τη σελίδα. Δεν υπάρχει φόρμα συλλογής στοιχείων ή νέα υπηρεσία αποστολής μηνυμάτων.

Τα κέντρα παρουσιάζονται στην Αρχική και στην Επικοινωνία ως ανοιχτή λίστα με μεγάλα ονόματα περιοχών, λεπτές διαχωριστικές γραμμές και άμεσες ενέργειες. Δεν χρησιμοποιούνται πλέον τα λευκά, στρογγυλεμένα κουτιά με χρωματιστό επάνω περίγραμμα.

Αμέσως μετά τις υπηρεσίες εμφανίζεται το λογότυπο μέσα από χρωματιστές κουκκίδες. Βάση του εφέ είναι η εγκεκριμένη δοκιμή `d613417`, με βελτιστοποιημένο κύκλο σχεδίασης που σταματά εκτός οθόνης, σε κρυφή καρτέλα και όταν η κύλιση σταθεροποιείται. Το πραγματικό λογότυπο δένει με το ανοιχτό φόντο μέσω CSS blending, χωρίς αλλαγή της εικόνας του. Το `assets/stars-mark.js` φορτώνεται μόνο στην Αρχική. Η προτίμηση μειωμένης κίνησης χρησιμοποιεί στατικό λογότυπο.

Η Αρχική έχει επίσης νέα σύνθεση καρτών, φωτογραφική σύνθεση με τις υπάρχουσες εικόνες του χώρου, εναλλαγές φωτεινών/σκούρων ενοτήτων, καθαρότερα βήματα έναρξης και επιλογή κέντρου. Δεν προστέθηκαν συνεχείς διακοσμητικοί βρόχοι animation ή νέα εξωτερική βιβλιοθήκη.

Βάση αντιγραφής: `dimitriskatik13-cmd/synoida-site`, commit `2b8735f901dd1f4c51741786c489cbe0a6a03db2`. Το repository αυτό δεν δημοσιεύει αλλαγές στο αρχικό repository ή στο synoida.gr. Παραμένει εκτός ευρετηρίασης με `noindex`.

## Επεξεργασία

Η πηγή κάθε σελίδας είναι το `_build/fragments/` και το κοινό κέλυφος το `_build/template.html`. Οι αλλαγές διάταξης της δοκιμής είναι στο `assets/preview.css`. Τα υπάρχοντα `assets/site.css`, αρχεία εικόνων και scripts κύλισης παραμένουν ίδια με την αρχική έκδοση.

```sh
python3 _build/build.py --keep-css
python3 -m http.server 8000 --bind 127.0.0.1
```

Η σημαία `--keep-css` κρατά το αρχικό στατικό CSS. Για νέες ενότητες χρησιμοποιούνται δικές τους κλάσεις στο `preview.css`, όχι νέες μη παραγμένες κλάσεις Tailwind.

Η δημοσίευση γίνεται από το `main`, root, στο GitHub Pages αυτού του repository. Κάθε αλλαγή αξιολογείται πρώτα εδώ. Η μεταφορά στην κύρια έκδοση αποτελεί χωριστή απόφαση.
